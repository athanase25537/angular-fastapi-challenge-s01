# 🚀 Challenge 8 Mois — Angular × FastAPI

> **Devenir un développeur Full Stack professionnel spécialisé en Angular & FastAPI en 8 mois.**

Ce repository contient mon parcours technique et les projets réalisés dans le cadre d'un **challenge personnel de 8 mois** consacré à Angular, FastAPI et à l'ingénierie logicielle moderne.

L'objectif n'est pas simplement de faire fonctionner une application, mais de comprendre **pourquoi les choix techniques sont faits**, de construire des applications maintenables, performantes, sécurisées et capables d'évoluer.

---

Pendant **8 mois — 32 semaines**, je vais progressivement approfondir :

---

# 🏆 Le défi

**8 mois — 32 semaines — 8 saisons — 8 projets.**

Chaque saison est consacrée à un domaine technique particulier et possède un **projet fil rouge** permettant de mettre immédiatement les connaissances en pratique.

La règle principale du challenge :

> **Apprendre → Implémenter → Tester → Mesurer → Refactorer → Documenter**

Je privilégie la compréhension et la qualité plutôt que la vitesse.

Si une notion demande plus de temps, je préfère prolonger son apprentissage plutôt que de simplement passer à la suite.

# 🧠 Philosophie d'apprentissage

Je ne cherche pas uniquement à apprendre des technologies.

Je cherche à comprendre :

* pourquoi utiliser une technologie ;
* quand ne pas l'utiliser ;
* comment choisir entre plusieurs solutions ;
* comment mesurer les performances ;
* comment écrire du code testable ;
* comment sécuriser une application ;
* comment faire évoluer une architecture ;
* comment diagnostiquer un problème en production.

Chaque choix technique important doit pouvoir être **expliqué et justifié**.
